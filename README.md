# Minecraft Python — уже игровая версия (Ursina)

Это уже не болванка: проект развился до **полноценного прототипа игры** с базовым геймплеем и оптимизациями.

## Что уже реализовано

- Процедурный мир из блоков (`трава / камень / бедрок`).
- Генерация рельефа на фрактальном value-noise (более плавно, чем чистый `random`).
- Камера от первого лица + управление `WASD`, прыжок `Space`, гравитация.
- Коллизии игрока с миром.
- Ломание и установка блоков:
  - `ЛКМ` — ломать,
  - `ПКМ` — поставить выбранный блок.
- Выбор блока:
  - `1` трава,
  - `2` камень,
  - `3` бедрок,
  - колесо мыши — переключение.
- Курсор в центре экрана.
- Подсветка/рамка выбранного блока (wireframe-outline).
- Голубое небо и освещение.
- Динамическая подгрузка чанков вокруг игрока.

## Оптимизация (сделано)

Чтобы игра работала заметно быстрее, реализованы ключевые пункты итерации оптимизации:

1. **Face culling (отсечение невидимых граней)**
   - В меш чанка добавляются только те грани блока, которые не закрыты соседями.
   - Внутренние грани не рендерятся.

2. **Mesh-чанки вместо Entity на каждый блок**
   - Раньше один блок = одна Entity (очень тяжело).
   - Сейчас чанк собирается в меши (по типам блоков), что резко снижает нагрузку на сцену.

3. **Кэш/пул чанков**
   - Чанки сохраняются в кэше.
   - При удалении из зоны рендера они отключаются, а не уничтожаются.
   - При возврате игрока в эту область используются повторно.

4. **Периодический апдейт стриминга чанков**
   - Обновление активных чанков происходит с интервалом, а не каждый кадр.

## Текстуры

Добавлена папка для текстур:

```text
assets/
└─ textures/
   ├─ README.md
   └─ blocks/
      ├─ .gitkeep
      └─ default_block.png   <- сюда можно положить свою текстуру
```

### Как подключить свою текстуру блоков

1. Положите файл в:
   - `assets/textures/blocks/default_block.png`
2. Перезапустите игру.

Сейчас по ТЗ используется **одна текстура для всех блоков**. Если файла нет, автоматически используется встроенная текстура Ursina `white_cube`.

## Управление

- `W A S D` — движение
- `Space` — прыжок
- `Mouse` — обзор
- `ЛКМ` — ломать блок
- `ПКМ` — поставить блок
- `1/2/3` — выбор блока
- `Колесо мыши` — переключение блоков
- `Esc` — выход

## Быстрый старт

### Linux / macOS

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python src/main.py
```

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python src/main.py
```
