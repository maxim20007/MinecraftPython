# Текстуры

Положите текстуры блоков в папку `assets/textures/blocks/`.

Базовый путь, который уже подключён в игре:
- `assets/textures/blocks/default_block.png`

Если файла нет — блоки рендерятся без текстур, но с разными цветами по типам.

Рекомендации:
- Размер: `16x16` или `32x32`.
- Формат: `PNG`.
- Пока игра использует одну и ту же текстуру для всех типов блоков.
